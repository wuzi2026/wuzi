备份说明

全部数据已保存在云端服务器，多人登录共享同一套数据；点击下方按钮可将全部数据导出为 JSON 备份文件保存到本地；旧单机版的数据可通过「导入恢复」迁入本系统（导入仅覆盖物资与出入库记录，不影响系统用户，用户始终以管理员录入的为准）

退出自动备份

每个账号可分别设置自己的备份文件夹：登录后点击「退出登录」会自动把全部数据备份到本人设置的文件夹，且文件夹内仅保留最近 3 个自动备份文件，更早的自动删除（需使用 Chrome / Edge 浏览器）。因浏览器安全限制无法自动读取完整路径，设置时会请您确认填写该文件夹的完整路径用于显示，实际备份位置以所选文件夹为准。登录后此处仅显示当前账号自己的备份路径与信息。

未设置，退出登录时不会自动备份
